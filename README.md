# Random Quizz

Jeu de quiz de soirée façon Jackbox : un hôte crée une salle, les joueurs rejoignent depuis leur téléphone (code ou QR code), mode solo disponible.

Stack : Next.js, React, Tailwind, PostgreSQL (Drizzle ORM).

## Lancer

```bash
npm install
# définir DATABASE_URL (PostgreSQL), puis :
npx drizzle-kit push
npm run dev
```
